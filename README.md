# EuroFour
This software revolutionizes the ATC24 radar creation community, because why spend time trying to compete against one of the most realistic radar softwares, if it already exists and we can just use it instead?

EuroFour is a community project created by Shayzee, which consists of EuroFour Bridge, a desktop application that fetches and updates data from the ATC24 server provided by 24data in real time, converts it into an FSD format, and populates it into EuroScope software.

EuroFour Plugin, a handmade plug-in that creates a dynamic ATC24 METAR list straight in EuroScope and automatically gets populated with all the airports that your connected position is responsible for in EuroScope. For each airport, it implements the active ATIS letter and METAR.
